# Computer Vision Projects

Academic computer-vision projects developed with Python and Jupyter notebooks.

## Projects

- `Proyecto-CNNflores.ipynb`: flower-image classification with a convolutional neural network
- `Proyecto-CubreBocas.ipynb`: face-mask detection exercise
- `Proyecto-Pahser.ipynb`: image-processing exercise
- `cascade.xml`: Haar cascade resource used by the computer-vision projects

## Stack

Python, Jupyter Notebook, computer vision, and convolutional neural networks.

## Notes

These are learning projects. The repository is kept in its original form to document the progression of my AI and computer-vision studies.
